# SHOW – Abbildungssystem

SHOW ist kein Operator.  
SHOW ist ein **Abbildungsmodul**.

Es zeigt nicht nur einen Zustand,  
sondern die **Figur**, die **Ursache**, die **Wirkung**  
und das **Echo** eines Raumes.

---

## 1 · Mathematische Definition

SHOW ist eine Abbildung:

SHOW(x) = x_echo

Dabei gilt:

- x bleibt unverändert  
- x wird sichtbar  
- x wird strukturiert  
- x wird gespiegelt  

SHOW ist **idempotent**:

SHOW(SHOW(x)) = SHOW(x)

---

## 2 · Physikalische Definition

SHOW ist ein Messoperator:

Ŝ |x⟩ = |x⟩

Der Zustand bleibt gleich,  
aber wird **sichtbar gemacht**.

SHOW erzeugt:

- Ursache  
- Wirkung  
- Echo(t)  

Echo enthält die Zeit:

echo.time = t

---

## 3 · Figur

Eine Figur ist ein Zustand mit Struktur:

- form  
- axis  
- orbit  
- pulse  
- layer  
- symbol  
- cause  
- effect  

SHOW bildet die Figur vollständig ab.

---

## 4 · Echo

Echo ist die Spiegelung der Figur:

echo = {
  form,
  axis,
  orbit,
  pulse,
  time
}

Echo ist die **sichtbare Version** des Zustands.

---

## 5 · OUR – Kombination

OUR(a, b) ist die Überlagerung zweier Werte:

OUR = a + b

Physikalisch:

|OUR⟩ = |a⟩ + |b⟩

Mathematisch:

OUR = [a, b]

---

## 6 · SHOW_UNIJ – Universalmodul

SHOW_UNIJ(figur) erzeugt:

- Figur  
- Layer  
- Symbol  
- Ursache  
- Wirkung  
- Echo(t)  
- Sichtbarkeit  
- Unverändertheit  

SHOW_UNIJ ist die **vollständige Abbildung**.

---

SHOW dient:

- der Sichtbarmachung
